Colour usage rules
  • Text is never below --ink-dim. Use --ink-dim, --ink, or --ink-bright for all text.
  • --ink-faint is never used for text — only borders, dividers, and structural hairlines.
  • No raw hex or rgba colour values anywhere in page files. Always use a token.
  • Never use the CSS opacity property to express colour intensity. Use the appropriate dim or tint token instead.

The physics, briefly

On a rotating station, your "gravity" comes entirely from the fact that the hull is constantly accelerating you inward — you're being flung outward, the hull pushes back, and that push feels like weight.

Now put a train on the inside. Travel spinward and your effective centripetal acceleration goes up. You feel heavier. Travel anti-spinward and your gravity drops.

Spacing & Layout

Shell CSS variables (defined in style.css, shared by all pages)
  • --header-h: 56px — sticky header height
  • --rail-w: 230px — fixed left rail width
  • --content-max: 750px — max readable width for prose pages
  • --serif: 'EB Garamond', Georgia, serif — shared font stack
Content padding (responsive)
  • Desktop: 52px 48px 120px
  • ≤860px: 36px 24px 80px
  • ≤480px: 28px 20px 72px
Responsive breakpoints
  • ≤860px — rail hidden, header padding collapses, page title → 40px
  • ≤480px — page title → 34px, content padding tightens further
Key spacing values
  • Paragraph bottom margin: 18px
  • Paragraph line-height: 1.44
  • Section spacing: 64–80px
  • Page divider bottom margin: 52–56px
  • Page title bottom margin: 26px
  • Page eyebrow bottom margin: 30px
  • Rail padding: 52px 32px 52px 48px
  • Header padding: 0 48px desktop · 0 24px at ≤860px
Special notes
  • The .poem archetype sets --content-max: 680px and larger padding via .content:has(.poem) — no local :root override needed on poem pages.
  • Canvas and Plotly chart colours must be hardcoded JS constants — update them manually when any palette token changes.
  • EB Garamond: weights 400 and 500 only. Do not add weight 600.
